# Official proposal PDFs

Drop the per-product proposal files here with EXACTLY these names:

- `iGV.pdf`
- `iGTa.pdf`
- `iGTe.pdf`

The "Attach the official proposal" option in the Proposal email popup reads
the matching file and attaches it to the Gmail draft. Missing file = the
option errors with a clear message. Keep each file under ~20 MB (Gmail limit
is 25 MB per message).
